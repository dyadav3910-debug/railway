🚆 Railway Reservation System

About the Project

This is a Railway Reservation System developed using C++ and Data Structures.

This project allows users to book tickets, cancel tickets, check train seat availability, and view passenger details.

Features

- Book Ticket
- Cancel Ticket
- View Train Seat Status
- View Passenger List

Technologies Used

- C++
- Array
- Singly Linked List
- Pointers
- Dynamic Memory Allocation
